# 🚀 Jakir Sir SMART Edu Portal

> Bangladesh's First Mobile-First Smart EduTech Platform for Bank & Government Job Preparation

---

# 📖 Project Overview

**Jakir Sir SMART Edu Portal** is a modern Mobile-First EduTech Web Application designed to bring all of Jakir Sir's educational resources into one unified platform.

Students will be able to:

- Enroll in courses
- Watch Live & Recorded Classes
- Practice MCQ
- Attend Mock Tests
- Download PDF Notes
- Read Blogs
- Follow Exam Routine
- Make Online Payments
- Access everything from a single dashboard

The platform is optimized primarily for **mobile users (90%+)**, while remaining fully responsive for tablets and desktops.

---

# 🎯 Vision

Create the most complete digital preparation platform for Bangladesh Government & Bank Job Aspirants.

Instead of using multiple Facebook pages, Messenger, YouTube, Google Drive, and PDF groups, students should find everything inside one application.
