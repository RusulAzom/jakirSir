# 📌 Design Philosophy

Our design follows one simple rule:

> **"Students should find everything within 3 taps."**

The interface must feel

- Modern
- Fast
- Clean
- Friendly
- Professional
- Mobile Optimized

The majority (90%+) of users will access the platform using Android smartphones.

Therefore,

**Every design decision starts from Mobile First.**

Desktop is simply an enhanced version.

---

# 🎯 Core Design Principles

## 1. Mobile First

Design everything for

```
375px
390px
414px
```

before designing for tablets or desktops.

---

## 2. Large Touch Area

Minimum touch target

```
48px × 48px
```

Buttons

Icons

Cards

Navigation

must be easily clickable.

---

## 3. One Primary Action

Every screen should have only one obvious primary CTA.

Examples

Home

> এখনই ভর্তি হন

Course

> Enroll Now

Exam

> Start Exam

Payment

> Pay Now

---

## 4. Clean Visual Hierarchy

Priority

```
Title

↓

Subtitle

↓

Information

↓

Action
```

Never overwhelm users with too many elements.

# 🎯 UX Goals

A student should be able to

✅ Find a course within 10 seconds

✅ Start an MCQ within 15 seconds

✅ Download a PDF within 2 taps

✅ Complete enrollment within 2 minutes

---

# 🚫 Avoid

❌ Small buttons

❌ Long paragraphs

❌ Too many colors

❌ Heavy shadows

❌ Slow animations

❌ Popups on every action

❌ Hidden navigation

❌ Horizontal scrolling (except carousels)

# 📌 Final Design Goal

Build a UI that feels as polished and intuitive as the best modern learning platforms while staying simple enough for every Bangladeshi student to use comfortably on a mobile phone.

Think:

- Duolingo (simplicity)
- Coursera (content organization)
- Unacademy (course discovery)
- PhysicsWallah (student-focused learning)
- Google Material Design (consistency)

Every screen should answer one question immediately:

> **"What should the student do next?"**
